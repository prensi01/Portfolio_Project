🗄️ What Is SQL?

SQL stands for Structured Query Language.

It is commonly used to interact with relational databases.

A Data Analyst can use SQL to retrieve, filter, summarize, and combine data to answer business questions.

A simple SQL workflow can look like this:

Business Question
        ↓
Find the Required Data
        ↓
Write SQL Query
        ↓
Filter / Transform Data
        ↓
Analyze Results
        ↓
Generate Insight

🔎 SELECT — Retrieving Data

The SELECT statement is one of the first SQL commands a beginner learns.

It is used to retrieve data from one or more columns.

Example
SELECT
    CustomerName,
    City
FROM Customers;

Instead of selecting every column, selecting only the required columns can make a query easier to read and more efficient.

Selecting all columns
SELECT *
FROM Customers;

🔹 DISTINCT — Finding Unique Values

DISTINCT can be used when we want unique values instead of repeated values. 

SELECT DISTINCT City
FROM Customers;

This can be useful when exploring a dataset and understanding which unique categories or locations are present.

🎯 WHERE — Filtering Data

The WHERE clause is used to filter records based on a condition. 

SELECT *
FROM Customers
WHERE City = 'Delhi';

We can also use comparison operators such as:

  • =
  • >
  • <
  • >=
  • <=
  • <>

Multiple conditions can also be combined using AND and OR. 

SELECT *
FROM Sales
WHERE SalesAmount > 10000
AND Region = 'North';

📊 ORDER BY — Sorting Data

ORDER BY is used to sort query results.

Data can be sorted in ascending or descending order.

SELECT
    ProductName,
    SalesAmount
FROM Sales
ORDER BY SalesAmount DESC;

Here, the products with the highest sales appear first.

🧮 Aggregate Functions

Aggregate functions are extremely useful for Data Analysts because they allow us to summarize large amounts of data.

Function Purpose
COUNT() Counts records
SUM() Calculates total
AVG() Calculates average
MIN() Finds minimum value
MAX() Finds maximum value
Example
SELECT
    COUNT(*) AS TotalOrders,
    SUM(SalesAmount) AS TotalSales,
    AVG(SalesAmount) AS AverageSales,
    MIN(SalesAmount) AS MinimumSale,
    MAX(SalesAmount) AS MaximumSale
FROM Sales;

📦 GROUP BY — Summarizing Categories

GROUP BY is used to group rows that have the same value in one or more columns.

It is especially useful with aggregate functions.

SELECT
    Region,
    SUM(SalesAmount) AS TotalSales
FROM Sales
GROUP BY Region;

This query can help answer a business question such as:

How much sales did each region generate?

🔍 HAVING — Filtering Groups

HAVING is commonly used with GROUP BY when we want to filter grouped results. 

SELECT
    Region,
    SUM(SalesAmount) AS TotalSales
FROM Sales
GROUP BY Region
HAVING SUM(SalesAmount) > 100000;

This query returns only the regions whose total sales are greater than 100,000.

WHERE filters individual rows, while HAVING filters grouped results.

🔗 JOIN — Combining Multiple Tables

Real-world databases often contain information across multiple tables.

JOINs allow us to combine related data from these tables.

INNER JOIN

An INNER JOIN returns records that have matching values in both tables. 

SELECT
    Customers.CustomerName,
    Orders.OrderID,
    Orders.OrderAmount
FROM Customers
INNER JOIN Orders
    ON Customers.CustomerID = Orders.CustomerID;

LEFT JOIN

A LEFT JOIN keeps all records from the left table and adds matching information from the right table. 

SELECT
    Customers.CustomerName,
    Orders.OrderID
FROM Customers
LEFT JOIN Orders
    ON Customers.CustomerID = Orders.CustomerID;

Understanding JOINs was an important part of my SQL learning because analytics projects often require information from multiple tables.

⚙️ CASE — Creating Conditional Logic

The CASE expression can be used to create conditional logic inside a query. 

SELECT
    CustomerName,
    SalesAmount,

    CASE
        WHEN SalesAmount >= 10000
            THEN 'High'
        WHEN SalesAmount >= 5000
            THEN 'Medium'
        ELSE 'Low'
    END AS SalesCategory

FROM Sales;

This can be useful when creating categories or business-friendly labels from raw data.

🔄 Subqueries

A subquery is a query written inside another query.

Subqueries can be useful when one query depends on the result of another query. 

SELECT
    ProductName,
    SalesAmount
FROM Sales
WHERE SalesAmount >
(
    SELECT AVG(SalesAmount)
    FROM Sales
);

This example finds sales records whose amount is greater than the overall average.

💼 SQL and Business Questions

Learning SQL became more meaningful when I started thinking about it from a Data Analyst's perspective.

Instead of asking only:

What SQL query should I write?

I started thinking:

What business question am I trying to answer?

For example:

  • Which products generate the most revenue?
  • Which region has the highest sales?
  • What is the average order value?
  • How many customers placed an order?
  • Which customers have not purchased recently?
  • Which month had the highest revenue?

These questions help determine which SQL concepts should be used.

STEP 01 Understand the Question Identify the business problem.
STEP 02 Understand the Tables Identify relevant columns and relationships.
STEP 03 Retrieve Data Use SELECT to get required columns.
STEP 04 Filter Data Use WHERE when conditions are required.
STEP 05 Summarize Use aggregate functions and GROUP BY.
STEP 06 Combine Tables Use JOINs when data is stored separately.
STEP 07 Analyze Results Look for patterns and meaningful insights.
STEP 08 Communicate Present the findings clearly.

🌱 What I Learned From SQL

2. Data Structure Matters

3. Practice Is Essential

4. Business Questions Come First
